# 危险操作清单（DeBox）

> AI 每次点击前必须比对本清单（TEST_GUIDE 铁律「危险操作 pre-action 比对」）。
> 命中 → 停下、截图、核对用例是否明确要求，未要求一律规避。
> 钱包 App 误操作不可逆：宁可 FAIL，不误点。

## 一、毁掉测试前提的操作（任何情况都禁止）

| 操作 | 命中特征 | 后果 |
|---|---|---|
| 清除 App 数据 | `pm clear` / 系统设置「清除数据」 | 丢登录态 + 切回正式环境，卡死在验证码 |
| 卸载/重装 | `uninstall` / 应用商店内更新重装 | 同上 |
| 登出 | 文本含「退出登录」「登出」「Log out」「Sign out」 | 丢登录态 |
| 切换环境 | SettingAdminActivity 内环境开关（进入路径见 `screens/SettingAdminScreen.md`：关于我们 → 连点 logo ×5 → 密码）；误点后弹「App必须重启」→ **一律取消** | 测试前提被破坏，且需重启才生效 |
| 切链（EVM/ETH/BTC 测试链） | SettingAdminActivity 内「EVM 测试链（切账号+链）」「BTC切测试环境」等按钮 | 走清 token 分支，丢登录态 |
| **切换账号（多账号设备）** | 「我的」页顶部「切换账号」弹层（rvWalletList 行本体点击即切） | 切到**真实账号**（emulator-5554 有 Kai/赵长鸟 两个真实号）= 测试前提破坏 + 真实资产/社交暴露在自动化下；误切后立即停操作、精确切回测试号（2026-07-11 事故） |
| **账号详情页** | 「切换账号」弹层行尾编辑按钮（ivEditWallet）→「账号详情」：**导出助记词/导出私钥/移除账号** | 助记词/私钥泄露（截图也禁止）、移除账号丢登录态 |

## 二、资金/资产类操作（仅用例明确要求 + 测试环境 + 测试数据时允许）

| 操作 | 命中特征 |
|---|---|
| **发红包** | 群聊「+」→「红包」→ 填数量/人数 →「生成红包」。⚠️ **2026-07-14 实证：这是链上操作**——走 `lucky_box/onchain_box/create`，需 BNB Chain **gas**；测试账号无 gas 时合约 `execution reverted: 0x8baa579f`，**红包发不出、无资金变动**（安全但测不了领取接口）。测红包领取前**先确认测试账号有 gas**；允许条件同本节（用例明确要求 + 测试环境 + 测试账号闭环 + 最小金额最少次数） |
| 转账/提现确认 | 「确认转账」「确认支付」「提现」「Send」「Confirm」+ 金额上下文 |
| 签名/授权 | 「签名」「授权」「Approve」「Sign」+ 钱包/DApp 上下文 |
| 删除/重置钱包 | 「删除钱包」「重置」「移除账户」 |
| 导出私钥/助记词 | 「导出」「备份」+ 私钥/助记词上下文（**截图也禁止**，截图会留存敏感信息） |

## 三、社交不可逆操作（用例明确要求才允许）

| 操作 | 命中特征 |

| 发布内容 | 「发布」「发送」到公开频道/群（测试消息需带 [autotest] 前缀且测试群内）；语音房「...」→「发布到动态」同属此类 |
